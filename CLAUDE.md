# UpNext Bar

macOS 26+ menu bar app (SwiftUI `MenuBarExtra`, `.window` style) for event countdown cards with reminders.

- Project is generated by XcodeGen from `project.yml`; never commit `UpNextBar.xcodeproj`, the generated `Info.plist` or entitlements.
- `make build`, `make test`, `make run`. Tests use Swift Testing.
- Dates are `CalendarDay` (year/month/day). Do day arithmetic only through `CalendarDay`/`Schedule`, never with raw `Date`.
- Keep `Logic/` and `Models/` free of SwiftUI/AppKit so they stay unit-testable.
- Every user-facing string must be in `UpNextBar/Resources/Localizable.xcstrings` with `en` and `uk` translations (Ukrainian plurals: one/few/many/other).
