# UpNext Bar

Застосунок для меню-бару macOS із картками важливих подій: дні народження, платежі, подорожі, релізи. Показує, скільки днів лишилось, і нагадує, коли подія наближається.

- Живе лише в меню-барі, без іконки в Dock.
- Яскраві картки з іконкою, кольором і зворотним відліком «через N днів».
- Повторення: щодня, щотижня, щомісяця, щороку. Повторювані події самі переходять на наступну дату.
- Нагадування в день події або за день до неї, у годину, вибрану в налаштуваннях.
- Одноразові події, що минули, переходять у секцію «Минулі».
- Можна показувати найближчу подію поруч з іконкою в меню-барі.
- Автозапуск при вході в систему.
- Мова інтерфейсу: українська та англійська. Світла і темна теми.

## Вимоги

- macOS 26 або новіша
- Xcode 26 або новіший
- [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`

## Збірка та запуск

```sh
make run      # згенерувати проєкт, зібрати Debug і запустити
make test     # юніт-тести
make open     # відкрити проєкт у Xcode
make install  # зібрати Release і скопіювати в /Applications
```

Файл `UpNextBar.xcodeproj` генерується з `project.yml` і не зберігається в git. Після зміни `project.yml` або додавання файлів запустіть `make project`.

Збірки підписуються ad-hoc («Sign to Run Locally»), тож Apple Developer акаунт не потрібен. Через це після кожної перезбірки macOS може знову спитати дозвіл на сповіщення. Автозапуск надійно працює для копії в `/Applications`, тому для щоденного користування ставте застосунок через `make install`.

Мову інтерфейсу можна змінити окремо від системної: «Системні параметри → Загальні → Мова та регіон → Застосунки».

## Структура

```
UpNextBar/
  App/        точка входу (MenuBarExtra) і AppModel: стан, навігація, планування нагадувань
  Models/     Event, CalendarDay (дата без часу й часового поясу)
  Logic/      розрахунок повторень, порядок карток, план нагадувань (чиста логіка, покрита тестами)
  Services/   збереження в JSON, налаштування, сповіщення, автозапуск
  Views/      SwiftUI-екрани: список, картка, редактор, налаштування
  Resources/  Localizable.xcstrings (en, uk)
UpNextBarTests/
```

Дані зберігаються в `~/Library/Containers/com.upnextbar.app/Data/Library/Application Support/UpNextBar/events.json`.
